# Report branding

Put the timing company's logo here as `report-logo.png` (or `report-logo.jpg`).
Every PDF report draws it top right in place of the "rfid-meet" wordmark,
fitted into a 220 x 64 pt box (wide or stacked logos both fit) with its aspect ratio kept.

- Best: a PNG with a transparent background cropped to the artwork, ~800 px wide (more only makes the PDFs bigger).
- PNG: 8-bit RGB/RGBA/gray or palette, not interlaced. JPEG: any baseline/progressive.
- A file that can't be read is logged and the wordmark is used instead.
