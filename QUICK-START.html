RFID Timing Console · Quick Start

Set up a Windows timing PC so the RFID mat, the LED clocks, FinishLynx and MeetPro work together. Plan on 20 minutes the first time, with FinishLynx and the reader at hand.

1What you need

  • A Windows 10 or 11 PC (64-bit) you can log in to as an administrator once.
  • FinishLynx with the LapTime plug-in installed on that PC.
  • The Vanch RFID reader (VF-747P or VF-787P) with its antennas, power supply and a network cable into the same switch as the PC and the FinishLynx camera.
  • Optional: the LED clocks on their USB-serial cables (CH340 = LED clock, PL2303 = Electro Numerics).
  • Optional: MeetPro, on this PC or on another laptop that can reach this PC's C:\Finish_Lynx_Results folder over the network.
  • Optional: Wireshark (free), so the console hears the start sensor through the camera.
  • The package: rfid-finishlynx-<date>-<version>.zip.

2Install

  1. Unzip the package anywhere (Desktop or a USB stick is fine). Right-click the zip, Extract All… Do not run it from inside the zip.
  2. Open the extracted rfid_finishlynx folder and double-click INSTALL.bat.
  3. If Windows says "Windows protected your PC": click More info, then Run anyway. Accept the administrator prompt.
  4. The installer works through 9 steps. It needs no internet. Answer its questions:
    It asksAnswer
    Open Network Connections now to set itOnly shown when the PC is not on the reader's network: Y, then see Network.
    Open the Wireshark download page nowY if you want starts from the camera. Install Wireshark with Npcap ticked. N is fine: you then set guns from the race pane.
    Change FinishLynx's settings nowClose FinishLynx first, then Y. It sets everything in section 4 for you and keeps a backup. N if you prefer to set them by hand.
  5. At the end the console starts and the browser opens http://localhost:8080. An RFID Console shortcut is on the Desktop, and the console starts by itself every time you log in.
Last step, if you were given a support key: Console chip → Updates & support, paste it into Support key, type a site name (your school or company), Save key. That lets Send logs reach whoever supports you.
Updates come through the same section: Update now appears when there is a newer version (the PC needs internet for that moment). Your settings, races and results are kept. Running a newer package's INSTALL.bat still works too.

3Network

The reader, the FinishLynx camera and this PC must be on the same wired network, 192.168.0.x:

DeviceAddress
RFID reader (factory setting)192.168.0.128
This PC's wired adapter192.168.0.200, mask 255.255.255.0, no gateway
FinishLynx camera (typical)192.168.0.201

If your camera network already uses 192.168.0.x, nothing to do. Otherwise set the PC's address: Win+R, type ncpa.cpl, right-click the wired adapter, Properties → Internet Protocol Version 4 (TCP/IPv4) → Use the following IP address.

The console finds the reader by itself, polls every antenna port it has, and turns the reader's beep off each time it connects: nothing to set on the reader.

4FinishLynx settings

Easiest: close FinishLynx and run C:\rfid_finishlynx\deploy\configure-finishlynx.bat (the installer offers the same). It shows what is wrong, changes only that, and saves a backup Lynx.cfg.before-rfid-<date> next to FinishLynx's settings. Open FinishLynx afterwards and check the screens below. To set them by hand:

All three are tabs of one Options dialog. Press Ok at the end to keep them.

4a. LapTime: RFID reads into FinishLynx

  1. FinishLynx menu LapTime → Options… (the LapTime plug-in must be installed).
  2. New (or pick the entry you use) and set Device: Lynx. Not IPICO, not BibLynx: those silently ignore the console.
  3. Serial Port: Network (listen), Port 5000. Sync. Source: Internal.

4b. Scoreboard: event, heat and race clock back to the console

  1. Menu Scoreboard → Options…, New, Name Middleware.
  2. Script: Example2.lss. Serial Port: Network (UDP), Port 5891, IP Address 127.0.0.1.
  3. Running Time: Normal (this is how the console learns the gun from FinishLynx). Results: Off.
One driver per LED clock. A clock that is also an entry in FinishLynx's own scoreboard list (for example "Timing_Clock" on a COM port) is driven by FinishLynx, and the console shows it amber ("port busy"). To have the console drive it instead (race time for the RFID races, time of day between), set that entry's Serial Port to <none>.

4c. Folders

Menu File → Options…:

Tab · settingFolderWhy
Database · Input DirectoryC:\Finish_Lynx_Results\RFIDMeetPro writes lynx.evt / .ppl / .sch here
Database · Output DirectoryC:\Finish_Lynx_ResultsFinishLynx saves its .lif files here (Write LIF File: On)
Event · Event DirectoryC:\Finish_Lynx_Resultssame folder
Why two folders: the console reads FinishLynx's .lif files from C:\Finish_Lynx_Results, adds the RFID mile splits, and writes the combined files into RFID, where MeetPro picks them up. FinishLynx and the console never write the same file.

5MeetPro settings

  1. MeetPro: Interfaces → F.A.T. → Setup.
  2. Directory = C:\Finish_Lynx_Results\RFID. From another laptop: the same folder over the network (share the timing PC's C:\Finish_Lynx_Results folder).
  3. Leave Don't Write Start Lists unticked. Export start lists as usual; they land in the RFID folder.
  4. For splits in MeetPro, use Splits Auto-Pull; for MileSplit Live during the race, Start MS Live Sync on the XC tab.
If the console ever stops mid-meet: point MeetPro's directory back to C:\Finish_Lynx_Results. Results keep flowing from FinishLynx; only the mile splits stop.

6Check it: Setup check

Open the console (http://localhost:8080 or the Desktop shortcut) and click the Console chip at the top left. Its Setup check lists everything above: ✓ is fine, ✗ needs fixing and says how, – does not apply yet (for example, no clock plugged in). Check again after each fix.

Some rows only turn green once things are running: the LapTime link when FinishLynx is open, the scoreboard feed once an event is armed, the camera once FinishLynx talks to it.

7Meet day

  1. Power up the reader, clocks and FinishLynx. The console starts by itself at login.
  2. Load meet… → Load. It reads the athletes MeetPro exported.
  3. Races from .evt: tick the races the mat will time, Add selected.
  4. Click Check-in on the next race.
  5. The gun arms the race by itself (camera start or FinishLynx's clock). Otherwise open the race's Gun ▾ and pick the start or Gun = now. The LED clocks follow the running race.
  6. Finishers appear as they cross. Needs attention lists anyone missing a mile split: Estimate, Add time or Publish without split.
  7. Close race when the last runner is in. The clocks go back to the time of day.
  8. After the meet: Export meet… for a CSV, then Close meet (archives everything, then clears the console for the next meet).

8When something is wrong

You seeDo
Stations chip red / "Reader offline"Reader power and network cable; PC on 192.168.0.x (section 3). The console reconnects by itself.
Reads in the console, nothing in FinishLynxFinishLynx LapTime Device must be Lynx on port 5000; an event armed and started.
LED clock darkSetup check → clock drivers. If FinishLynx's own scoreboard list has an entry on that clock's COM port, FinishLynx holds the port: remove that entry or pick a different clock.
Clock shows the wrong thingClocks chip → Back to auto.
Gun not picked upRace Gun ▾ → pick the start or Gun = now. For camera starts: Wireshark installed, FinishLynx open.
MeetPro shows no splitsMeetPro's F.A.T. directory = the RFID folder (section 5).
Console page does not loadDouble-click the Desktop RFID Console shortcut, then reload the page (F5).
After an update, buttons look oldReload the page (F5).
The new version misbehavesConsole chip → Roll back. If it will not even start, it goes back to the previous version by itself after three tries.
Anything else oddConsole chip → type what happened (with the time) → Send logs. Do it the same day: the logs keep two weeks.
